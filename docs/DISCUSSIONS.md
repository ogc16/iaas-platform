# Community Guidelines

This project uses **GitHub Discussions** for everything that is not a tracked bug or a security report. Bugs go to [Issues](../../../issues) (use the bug template); security vulnerabilities go to [SECURITY.md](SECURITY.md) via the private advisory flow.

## How to use the categories

| Category | Use it for |
|----------|------------|
| **Announcements** | Maintainer news, releases, and roadmap updates. Read-only for everyone else. |
| **General** | Anything that fits nowhere else — meta talk, show-and-tell, community chatter. |
| **Ideas** | Feature requests and product suggestions. Upvote existing ideas instead of posting duplicates. |
| **Q&A** | Help and questions about using or deploying the platform. Search before asking. |
| **Show and tell** | Projects you built with the IaaS Platform, integrations, or deployments. |
| **Polls** | Community decisions — prefer a poll to a wall of opinions. |

## Etiquette

- **Assume good faith.** Someone who disagrees with you is still a contributor. Argue the idea, not the person.
- **Be concise but complete.** A title that summarizes the topic, and a body that gives enough context to answer without a follow-up round-trip.
- **Search before posting.** Check existing discussions, issues, and the [docs](../README.md#documentation) first. Duplicates get closed and merged into the canonical thread.
- **Use the right channel.** Feature requests belong in *Ideas*, questions in *Q&A*, bugs in *Issues*, security in the private advisory flow. Off-topic posts may be moved or closed.
- **No spam or self-promotion.** Linking your project in *Show and tell* is welcome; promotional noise is not.
- **Report, don't fight.** If a post violates GitHub's [Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines), flag it for the maintainers instead of engaging.

## Maintainer response

- Maintainers read every discussion and answer **Q&A** in the order posted — usually within a few days.
- **Ideas** that fit the product get added to [ROADMAP.md](ROADMAP.md) and linked from their discussion.
- Small, well-scoped tasks are filed as *good first issues* (see the [issues list](../../../issues)) and are open to anyone, including first-time contributors.
- Announcements are posted for releases (see [CHANGELOG.md](CHANGELOG.md)) and milestone decisions.

## What happens to non-conforming posts

- Duplicates → closed and linked to the canonical thread.
- Off-topic → moved to *General* or closed with a pointer.
- Spam or abuse → removed and reported. Repeat offenders are blocked.

Thanks for helping keep this a welcoming, useful community.
